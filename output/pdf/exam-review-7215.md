## 03 / 理论短文：机器学习与经典统计
> 明确题目：定义 ML、比较 classical statistics，并给出基本学习任务及应用。题目提示六个比较维度。［V2 08:10-14:55］

### 可以直接使用的定义
机器学习是人工智能的一个分支：从数据中学习模式与输入输出关系，以改善任务表现，并利用学到的模型对新数据作预测、分类或决策，而不是为每一种情况手工编写规则。

### 六个维度的比较框架
| 比较维度 | 经典统计：课件强调 | 机器学习：课件强调 |
| --- | --- | --- |
| Main Goal 主要目标 | 理解关系、解释数据。 | 准确预测未来或未知结果。 |
| Focus 关注点 | 推断、解释、假设检验。 | 预测、自动化与泛化。 |
| Data Size 数据规模 | 课件概括为通常较小。 | 课件概括为经常使用较大数据集。 |
| Model Complexity 复杂度 | 通常偏简单、易解释。 | 可使用较复杂的模型。 |
| Success Measure 评价 | 显著性、模型拟合等。 | 预测准确性及对未见数据的泛化。 |
| Example 示例 | 研究运动与健康的关系。 | 预测患者是否会出现某疾病。 |

### 答题时要避免的过度简化
**这是关注点的比较，不是互斥定义。**统计方法也能预测，机器学习也可能解释；两者都能从数据估计参数，也都可能使用复杂模型或不同规模的数据。

课件另有一幅“输入＋规则→输出”与“输入＋输出→学习规则”的图，描述的是**传统编程与机器学习**。不要将“经典统计完全等于程序员写死规则”作为严格定义。比较统计与 ML 时，优先使用“推断与解释”相对“预测与泛化”的主线。

### 推荐的短文结构
- 先用 1-2 句话定义 ML，再按题干提示的六个维度列表。
- 举一个具体例子：利用已标记的历史垃圾邮件学习特征，对新邮件分类。
- 若题干还要求 fundamental tasks，补上分类、回归、聚类等的定义与例子，不能只有 ML 与统计的比较。

## 04 / 图解与辨析：学习范式不能混淆
> 明确题目：#2 比较监督、无监督并归类五种任务；#3 判断手写数字识别与机器人游戏的学习方式。［V2 14:57-25:25］

### 一张可背出的结构图
```
Machine Learning 机器学习
  Supervised Learning 监督学习：有配对输入与目标标签
    Classification 分类：输出离散类别
    Regression 回归：输出连续数值
  Unsupervised Learning 无监督学习：无给定目标标签
    Clustering 聚类：发现相似样本群组
    Association 关联：发现共同出现的模式或规则
    Dimensionality Reduction 降维：以较少维度保留重要结构
  Reinforcement Learning 强化学习：行动后依据奖励改进策略
```

| 任务 | 一句话定义 | 日常类比 / 应用 |
| --- | --- | --- |
| 分类 | 根据标记样本学习类别边界。 | 看带标签照片学习识别猫或狗。 |
| 回归 | 学习输入到连续目标的映射。 | 利用面积等特征预测房价或长度。 |
| 聚类 | 在无类别标签时按相似性分组。 | 将一堆衣物按相似特征分堆，之后再为各堆命名。 |
| 关联 | 找到经常共同出现的项目或关系。 | 分析哪些衣物经常搭配，或商品经常被一起购买。 |
| 降维 | 用较少特征表达数据的关键结构。 | 将很多衣物属性压缩为少数主要维度。 |

### #3 的标准推理路径
- **带数字标签的 MNIST 图像→监督学习。**训练样本给出图像及正确数字，模型学习两者关系，再分类新图像。决定因素是存在目标标签。
- **机器人反复玩游戏并提升得分→强化学习。**机器人通过行动与环境交互，获得得分奖励并改进策略；没有预先给出每一步正确动作。
- **不能看到“没有标签”就一律写无监督。**题干若强调 action、reward、trial and error，应优先识别强化学习。

> 术语提醒：课件在降维旁使用了 generalization 一词。严格理解时，降维是减少特征维度；泛化是模型在未见数据上的表现，两者不能直接画等号。以上为概念校正。

## 05 / 网络基础与拓扑短答
> 来源：V1 00:34-02:13；V2 00:00-01:56、07:21-07:53。此页将老师点名的术语整理为短答框架；#8 的具体题干未展示。

### 一个神经元：先会说清计算顺序
```
输入 x → 与权重 w 相乘并求和 → 加偏置 b → 激活 f → 输出 ŷ
z = wᵀx + b； ŷ = f(z)
```
- **Weight 权重：**控制每个输入对线性组合的贡献，是训练要调整的参数。
- **Bias 偏置：**改变激活前的平移项；可单独写 b，也可能由常数输入与权重表示，须服从题目约定。
- **Activation 激活：**决定如何把线性组合变成输出。signum 给离散结果，identity 保留原值，tanh 给平滑非线性。
- **Learning rate 学习率：**控制每次更新步幅。不要把它与预测误差、批次大小混为一谈。
- **Forward / backward：**前向传播求输出与损失；反向传播通过链式法则求梯度；参数更新是随后执行的步骤。

### 网络比较：用四个问题作答
| 模型 | 核心结构与信息流 | 复习时应讲清的差别 |
| --- | --- | --- |
| 前馈 ANN / MLP | 信息沿层次从输入到输出，无循环状态。 | 普通结构没有显式递归状态；层数、隐藏单元和激活影响表示能力。 |
| RNN | 引入状态与跨时间的信息传递。 | 面向有顺序的数据；当前输出可受历史状态影响。 |
| LSTM | 在循环网络中加入记忆与门控机制。 | 设计用于更好地保留和控制较长期信息；应能解释为何用于序列任务。 |
| RBF 网络 | 以径向基函数构造隐藏层响应。 | 本录屏仅点名案例；具体结构与训练计算须回到 Chapter 03 原例。 |

### 拓扑短答示例框架［补充归纳］
“普通前馈网络按层处理给定输入；RNN 通过隐藏状态传递序列历史；LSTM 进一步利用记忆及门控调节信息保留与遗忘。因此，比较语言任务模型时，应说明如何表示顺序与历史，而不是只列模型名称。”

老师提到语言模型的发展，但两段录屏没有展示 #8 的具体题目，也没有确认某个新模型的详细公式题。优先把 ANN、RNN、LSTM 的结构与区别讲通，再依据原课件补充。

## 06 / 计算题的共同规则与数据
> 明确题目：Exercise #4；#5 沿用同一数据和批次。［V2 25:25-32:30、40:50-42:10］

| 样本 | 输入向量 x | 目标 y |
| --- | --- | --- |
| 1 | [1, 1, 2, 3] | +1 |
| 2 | [1, 1, 1, 1] | +1 |
| 3 | [1, -1, -1, -1] | -1 |
| 4 | [1, -2, -2, -2] | -1 |

```
初始权重 w⁽⁰⁾ = [0, 0.1, 0.2, -0.3]；学习率 η = 0.01
第 1 次迭代：B₁ = {1, 4}；第 2 次迭代：B₂ = {2, 3}
eᵢ = yᵢ - ŷᵢ
Δw = η Σ(i∈B) eᵢxᵢ；w_new = w_old + Δw
```

### 每个批次都按六步写
- 1. 写清该批次使用的旧权重。
- 2. 对每个样本算 zᵢ＝w_oldᵀxᵢ。
- 3. 根据本题激活函数计算预测 ŷᵢ。
- 4. 算误差 eᵢ＝目标减预测。
- 5. 汇总该批次所有样本的 ηeᵢxᵢ。
- 6. 批次结束时统一更新，下一批次使用新权重。

### 这三项约定直接影响答案
**同一批次内使用同一组旧权重。**不能处理完样本 1 就立刻用新权重计算样本 4；那会变成另一种更新方式。

**题目采用求和更新。**给出的规则没有除以批次大小，也没有额外的 2。即使看到“MSE”，也应先服从题干给出的更新公式。

**不额外添加偏置。**#4 写明 without bias，但向量首项都是 1；#5 又用 w₀ 写线性组合。按题面原有四维向量与四个权重算即可，不自行加第五个参数，也不删除首项。此为题面记号差异提醒。

## 07 / Exercise #4：signum 感知机
> 明确题目与课件答案：V2 25:25-40:30。以下数值按给定更新规则独立复算，与展示答案一致。

```
sgn(z)：z > 0 时为 +1；z = 0 时为 0；z < 0 时为 -1
ŷᵢ = sgn(wᵀxᵢ)
```

### 第一次迭代：用 w⁽⁰⁾ 处理样本 1 与 4
样本 1：z₁＝0×1＋0.1×1＋0.2×2－0.3×3＝-0.4。
所以 ŷ₁＝-1，e₁＝1－(-1)＝2。
```
Δw₁ = 0.01 × 2 × [1, 1, 2, 3]
     = [0.02, 0.02, 0.04, 0.06]
```
样本 4：z₄＝0×1＋0.1×(-2)＋0.2×(-2)－0.3×(-2)＝0。
所以 ŷ₄＝0，e₄＝-1－0＝-1。
```
Δw₄ = 0.01 × (-1) × [1, -2, -2, -2]
     = [-0.01, 0.02, 0.02, 0.02]
Δw⁽¹⁾ = Δw₁ + Δw₄ = [0.01, 0.04, 0.06, 0.08]
w⁽¹⁾ = [0.01, 0.14, 0.26, -0.22]
```

### 第二次迭代：用 w⁽¹⁾ 处理样本 2 与 3
| 样本 | 内积 z | 预测与误差 |
| --- | --- | --- |
| 2 | 0.01＋0.14＋0.26－0.22＝0.19 | ŷ₂＝+1；e₂＝1－1＝0。 |
| 3 | 0.01－0.14－0.26＋0.22＝-0.17 | ŷ₃＝-1；e₃＝-1－(-1)＝0。 |

因此 Δw⁽²⁾＝[0, 0, 0, 0]，最终 **w⁽²⁾＝[0.01, 0.14, 0.26, -0.22]**。

### 必须理解的考点

## 09 / Exercise #6：反向传播完整推导
> 明确题目：V2 49:50-52:47 展示题干并开始讲解。以下给出便于复习的独立推导；录屏在讲解过程中结束，并未展示完整数值答案。

> 考试提示：老师说明若需特定函数的导数，会提供提示。重点是会用提示推导，而不是只记住 tanh 的导数。［V2 51:29-52:06］

### 题目结构与损失
单输入 x，两个 tanh 隐藏单元，线性输出；题目没有额外偏置项。
```
h₁ = tanh(w₁x)；h₂ = tanh(w₂x)
ŷ = v₁h₁ + v₂h₂
L = ½(ŷ - y_true)²；e = ŷ - y_true
```

### 链式法则：先输出层，再隐藏层
```
∂L/∂ŷ = e
∂L/∂v₁ = e h₁；∂L/∂v₂ = e h₂
∂L/∂w₁ = e v₁ [1 - tanh²(w₁x)] x
∂L/∂w₂ = e v₂ [1 - tanh²(w₂x)] x
```
隐藏层梯度包含四个因子：**输出误差 × 输出层权重 × tanh 导数 × 输入**。每一项都来自计算路径上的一个局部导数。

### 代入题目给定数值
x＝1，y_true＝0，w₁＝w₂＝v₁＝v₂＝1。
```
tanh(1) ≈ 0.761594；h₁ = h₂ ≈ 0.761594
ŷ ≈ 1.523188；e ≈ 1.523188；L ≈ 1.160051
∂L/∂v₁ = ∂L/∂v₂ ≈ 1.160051
∂L/∂w₁ = ∂L/∂w₂ ≈ 0.639700
```

### 容易漏掉的三件事
- 损失已有 ½，求导后为 e，不额外乘 2。
- 隐藏层梯度不能漏掉 vᵢ，也不能漏掉输入 x。
- 这是**梯度**；若题目要求更新参数，才按 θ_new＝θ_old－η∂L/∂θ 执行。原 #6 题未给学习率，不虚构更新后的参数。

> 与 #4/#5 的符号对照：本页 e＝预测减目标；前两题更新公式用的是目标减预测。两种记法都可以，但代入更新式时必须保持一致。数值梯度已用有限差分验证。
